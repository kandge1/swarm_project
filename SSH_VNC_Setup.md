# SSH Setup:
1. Ensure that both the robot and the client computer are connected to the same network [WiFi@OSU tutorial] (https://github.com/kandge1/swarm_project/blob/myagv_main/WiFi%40OSU_Tutorial.md)
2. On the robot, click the WiFi icon in the top right corner, then go down and click Connection Information
3. Record the IP Address under IPv4 (should be something like 172.30.29.55)
4. On your client computer, open a terminal and enter `ssh er@<ROBOT_IP>` make sure to replace <ROBOT_IP> with the IP address from the previous step
5. Enter the login information for the robot (default: Elephant)
