THE DESIGN DECISION FOR TODAY: THE CALIPER IS THE METRIC, NOT THE TAPE
---------------------------------------------------------------------
The caliper at the 8 mm park reads the fingertips against the PHYSICAL BLOCK.
It does not care where the mat was meant to be, so it is immune to every
problem above. The truth column becomes a cross-check, not the metric.

This also means we do NOT spend the morning re-measuring 15 mat positions
with a steel rule. That was the alternative and it is slow, hateful, and
still only as good as the person doing it at hour seven.

THE INSTRUMENT (verified in code this morning, not guessed)
    python3 explore_pick_place.py --any-block --skip-pick --position X

  --yes is forwarded ONLY if you pass it (explore_pick_place.py:501), so
  without it the confirm loop runs, and the measurement park lives inside
  that loop (tag_pick_place.py:2182). Sequence:
    survey pickup + place -> park at the hover -> lower to 8 mm fingertip
    clearance above the block's TOP FACE -> block report -> prompt.
  At the prompt: caliper, then type "dx dy" in mm, or ENTER to accept.
  --skip-pick returns before any descent, so THE BLOCK NEVER MOVES and a
  repeat at the same position starts from an identical scene. Free repeats.

  Truth-on-centre is forwarded by default; pass --no-truth-block-on-centre
  only when the block is deliberately OFF the zone centre (Q2).
  Add --note sun_<what> so today's rows are findable.
